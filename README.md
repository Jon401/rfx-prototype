# RFX Procurement Portal (Prototype)

Interactive Phase 1 prototype for buyer and supplier RFX workflows — RFIs, RFQs, and RFPs with invitations, Q&A, submissions, scoring, and award/close.

Built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui. State is persisted in the browser via localStorage (use **Reset Demo** in the app to reload seed data).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and switch users from the header to explore buyer vs supplier views.
